# Tests et validation

Ce répertoire accueillera les tests unitaires, tests d'intégration et scénarios de validation manuelle.

Un test doit décrire :

1. les prérequis ;
2. les étapes d'exécution ;
3. le résultat attendu ;
4. le résultat observé ;
5. les conditions d'échec.

Un workflow qui s'importe sans erreur n'est pas automatiquement considéré comme fonctionnel. Les étapes de publication doivent toujours être testées dans un environnement privé avant utilisation publique.

# Contribuer à OpenContentAI

Merci de t'intéresser au projet. Les contributions sont utiles même si le moteur est encore en construction.

## Avant de proposer une modification

1. Décrire le problème ou l'amélioration recherchée.
2. Garder les intégrations propres à un fournisseur séparées du moteur principal.
3. Ne jamais ajouter de secrets, médias privés ou ressources protégées qui ne peuvent pas être redistribuées.
4. Mettre à jour la documentation concernée.
5. Fournir des étapes reproductibles et le résultat attendu.
6. Mesurer l'impact CPU, RAM, VRAM et stockage lorsqu'une dépendance ou un modèle lourd est ajouté.
7. Indiquer clairement si la modification est testée ou encore expérimentale.

## Domaines de contribution

- workflows n8n ;
- adaptateurs de modèles locaux ;
- synthèse vocale ;
- workflows ComfyUI ;
- génération et traitement vidéo ;
- intégrations YouTube et TikTok ;
- contrôle qualité automatique ;
- gestion des ressources ;
- documentation et profils éditoriaux.

## Convention de commit

Exemples :

```text
feat: ajouter le retour de validation Telegram
fix: bloquer la publication après un échec du rendu
docs: documenter la configuration WSL2
chore: mettre à jour les variables d'environnement
```

## Liste de contrôle d'une demande de contribution

- [ ] Aucun secret ni donnée privée.
- [ ] Documentation mise à jour.
- [ ] Étapes de test fournies.
- [ ] Impact sur les ressources évalué.
- [ ] Droits des médias et licences vérifiés.
- [ ] Comportement de publication sûr : aucune approbation implicite.
